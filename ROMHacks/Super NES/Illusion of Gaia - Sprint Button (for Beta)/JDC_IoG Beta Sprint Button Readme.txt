Illusion of Gaia - "Sprint Button (for Beta)"
  A Super NES ROM hack by C-Dude and JCollins2048

**Important**
This patch is intended for the Illusion of Gaia prototype from May 19, 1994.

---

[Introduction]
This is a port of a ROM hack by C-Dude which adds a dedicated sprint button
to Illusion of Gaia. This one is for a prototype localization build.

I did not get explicit permission to do this, but my work is based on Raeven0
and C-Dude's public work, and I've shared all of my work as well, so I don't
believe there should be a problem.

[Package Contents]
- JDC_IoG Beta Sprint Button -- The main hack.

[Tested CRC32 ROM Hashes]
- CE90286B -- Illusion of Gaia (USA) (Beta, No Header)

[Tools Used]
- XVI32 -- http://www.chmaas.handshake.de/delphi/freeware/xvi32/xvi32.htm
    A simple hex editor. Used to find the title screen tiles.

- Snes9x -- https://github.com/snes9xgit/snes9x
    A Super Famicom and Super NES emulator. Used to test the edits.

- Floating IPS -- https://git.disroot.org/Sir_Walrus/Flips
    A ROM patching and patch-making program. Used to make and test patches.

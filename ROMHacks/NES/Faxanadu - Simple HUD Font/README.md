Faxanadu - "Simple HUD Font" (aka "SHUDF")
  An NES ROM Hack by JCollins2048

---

[Introduction]
These patches replace the default Faxanadu HUD and menu font.
Any patch works in *any* version of the game, as far as I know.

[Package Contents]
- JDC_Faxanadu SHUDF (Basic) -- USA Revision A font.
- JDC_Faxanadu SHUDF (Bold) -- Same, but thicker.
- JDC_Faxanadu SHUDF (Italic Basic) -- USA Revision A font, but diagonal.
- JDC_Faxanadu SHUDF (Italic Bold) -- Same, but thick and diagonal.
- JDC_Faxanadu SHUDF (Shadow) -- USA Revision A font with a nice shadow.

[Tested CRC32 ROM Hashes]
- 3d00016e -- Faxanadu (Europe)
- 2720e7ac -- Faxanadu (Japan)
- d8f265fc -- Faxanadu (USA)
- 6832f445 -- Faxanadu (USA) (Rev 1)

[Tools Used]
- YY-CHR -- https://w.atwiki.jp/yychr/
    A graphic tile editor. Used to edit the graphics.

- Famicom Emulator Ultra X -- https://fceux.com/web/home.html
    A Famicom and NES emulator. Used to test the edits.

- Floating IPS -- https://git.disroot.org/Sir_Walrus/Flips
    A ROM patching and patch-making program. Used to make and test patches.

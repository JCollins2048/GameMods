Castlevania: Dawn of Sorrow - "Extra Items"
  A Nintendo DS ROM hack by JCollins2048

---

[Introduction]
This hack adds "extra" items into the main game -- specifically the
Julius Mode-specific items and "Souls".

Yes, I renamed Julius' Cross (boomerang) as "Crucifix". It's what Konami was
doing at the time.

I also did a tiny bit of tinkering with some relevant stuff.
For, ya know, the sake of completion.

[Package Contents]
- JDC_Castlevania DoS - Extra Items -- The hack.

[Tested CRC32 ROM Hashes]
- 135737F6 -- Castlevania: Dawn of Sorrow (USA)

[Known Bugs]
_All versions_
- Soma looks odd -- sometimes VERY -- when using the "Julius Mode" stuff.
    - The player was never meant to use that stuff, so go figure?
- When playing Julius Mode, the Soul-Keepers that contain Julius Mode souls
  STILL APPEAR WITHIN THE MAPS even if all three characters are collected.
- This ROM hack is probably NOT COMPATABLE with other ROM hacks.

[Tools Used]
- DSVEdit (https://github.com/LagoLunatic/DSVEdit)
    An all-in-one GBA / DS Castlevania editor.
    This was where I did most of the editing.

- XVI32 -- http://www.chmaas.handshake.de/delphi/freeware/xvi32/xvi32.htm
    A simple hex editor. Used to alter the script.

- Mega Man 7 De/Compression Tools -- https://www.romhacking.net/utilities/1255/
   Invaluable to this project. I couldn't have edited graphics without them.

- YY-CHR -- https://w.atwiki.jp/yychr/
    A graphic tile editor. Used to edit the graphics.

- melonDS -- https://melonds.kuribo64.net/
    A very nice, low-overhead, feature-rich Nintendo DS emulator.
    Used this while testing my edits.

- Floating IPS -- https://git.disroot.org/Sir_Walrus/Flips
    A ROM patching and patch-making program. Used to make and test patches.

Pokémon Red and Blue Versions - "Satin Version"
  A Game Boy ROM hack by JCollins2048

---

[Introduction]
It's a ROM hack that replaces everyone's favorite mute protagonist with the
semi-unused third character -- a girl seen in some old promotional art.

The full version also changes some bits of the script.
...
I utterly lost sight of what I was doing with this hack.

Just use the "player only" version.

[Package Contents]
- JDC_Pokemon Red / Blue - Satin Version (Full) -- Graphic and text changes.
- JDC_Pokemon Red / Blue - Satin Version (Player) -- Just the player char.

[Tested CRC32 ROM Hashes]
- d6da8a1a -- Pokemon - Blue Version (USA, Europe) (SGB Enhanced)
- 9f7fdd53 -- Pokemon - Red Version (USA, Europe) (SGB Enhanced)

[Known Bugs]
_All versions_
- This does not work with Randomizer hacks.
- I may have missed a typo or three.

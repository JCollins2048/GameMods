# J. Collins' Rando-Dalton Imperial Character Palettes

Whatever palettes I came up with for use with the [Rando-Dalton Imperial](https://ctrando.com/) *Chrono Trigger* Randomizer.

*<small>(Last updated on 10/25/2026)</small>*

## Usage Instructions
### The Easy Way

- Grab (and combine?) the desired `toml` file(s), then load them as **a personalization (`.toml`) file** in the randomizer

### The Hard Way

- Under the **[toml builder](https://ctrando.com/toml_form)** page, go to **Post Rando Options**
- Manually copy and paste the desired palettes for the desired characters
- Save the `toml` and add it as either the **custom settings** file or the **personalization file**

### `toml` Layout

No matter the way you do it, the palette part of your `toml` file should read something like this:

```
crono_palette = "12 palette values (HexRGB)"
marle_palette = "12 palette values (HexRGB)"
lucca_palette = "12 palette values (HexRGB)"
 frog_palette = "12 palette values (HexRGB)"
 robo_palette = "12 palette values (HexRGB)"
 ayla_palette = "12 palette values (HexRGB)"
magus_palette = "12 palette values (HexRGB)"
```
